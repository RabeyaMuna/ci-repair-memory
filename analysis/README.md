# Analysis Scripts

This folder contains scripts for analyzing benchmark results and generating statistics.

## Scripts

- `analyze_failure_type_success_rates.py` - Analyzes success rates by failure type
- `analyze_results.py` - General results analysis
- `analyze_unsuccessful_causes.py` - Analyzes causes of unsuccessful runs
- `export_commit_counts_csv.py` - Exports commit statistics to CSV
- `generate_section6_statistics.py` - Generates statistics for paper Section 6
- `statistical_significance_test.py` - Performs statistical significance tests

## Usage

Run these scripts after benchmark execution to analyze results.
